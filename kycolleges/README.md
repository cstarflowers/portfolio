# KY Colleges / EKU-Admissions 
_Internship (YLP12)_, Computer Science @ Ignite

## Information
A project created for Eastern Kentucky University and Rise Up Academics intended to provide another channel in which prospective students can learn more about the university and the admissions process, easing their concerns and providing them with the resources they need to make their college experience as impactful as it can possibly be!
