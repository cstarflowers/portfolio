# Carson's Portfolio
Welcome to my digital portfolio! In this repository, you'll find my resume and several different folders, each containing their own project description, images/videos, and code samples. For a brief description of all the projects contained in this portfolio, please see the following:

**Silhouette:** Silhouette is a 2022 rhythm-based RPG game created entirely in C# via Unity. It was created as part of a student initiative to shed light on mental health concerns in Kentucky public schools, and thus utilizes a wide variety of professional research and personal anecdotes alongside its design and code. Silhouette is currently publicly available in its entirety [here](https://github.com/cstarflowers/silhouette-DEV).
