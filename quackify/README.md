# Quackify
Project 1 (CS1332), Computational Media @ Georgia Tech

## Information
A solo project created for my Data Structures and Algorithms class at Georgia Tech. It's designed as a duck-themed alternative to Spotify, with similar features and an easy-to-use user interface. Some code is partially supported by class TAs, denoted at the top of code snippets as "CS1332 TAs."
